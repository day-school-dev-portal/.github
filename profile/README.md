# Day School Dev Portal

A shared home for software that Jewish day schools build for themselves.

Schools spend a great deal of effort solving the same problems separately —
scheduling, rosters, assessment, communication, the endless reshaping of data
between systems that were never meant to talk to each other. Most of that work
is thrown away when the person who did it moves on, and the next school starts
from nothing.

This is a place to stop doing that. Small, practical tools, released openly, so
that a school with a problem can start from someone else's answer.

## What you'll find here

Everything here is meant to be **downloaded and used**, not admired. The bar for
anything published in this org:

- **It runs.** Clone it, open it, and it works. No accounts to create, no keys
  to obtain, no build step, wherever that is possible.
- **It explains itself.** A README written for a person who has never seen the
  project, and a `CLAUDE.md` so that Claude Code can pick it up and help you
  change it.
- **It holds no school data.** These are tools, not databases. Student
  information stays inside your own systems, on your own machines.

## Projects

**[group-maker](https://github.com/day-school-dev-portal/group-maker)** — paste
a class list, get groups, print them. One HTML file, works offline.

More to come as they are ready.

## Using these at your school

Take them. Fork them. Change the names, change the colors, strip out the parts
you don't need. Everything here is MIT licensed, which means you can use it in
your school without asking anyone, including commercially, as long as the
copyright notice comes along.

If you improve something, a pull request is welcome but not expected. The point
is that the work exists somewhere other than one person's laptop.

## About

Started by educators at Solomon Schechter Day School of Greater Boston, built
with Claude Code, and open to any day school that wants to contribute.
